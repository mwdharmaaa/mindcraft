# MindCraft

High-performance, customizable infinite mind mapping canvas with dynamic node schemas, keyboard navigation, and theme customization.

## Architecture & Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Canvas Engine:** React Flow (`@xyflow/react`)
- **State Management:** Zustand
- **Styling:** Tailwind CSS (Linear-inspired neutral dark palette)
- **Icons:** Lucide Icons
- **Layouting:** Tree and Hierarchical DAG algorithms
- **Containerization:** Docker + Single-enter bash orchestration (`deploy.sh`, `redeploy.sh`, `test.sh`)

## Quick Start

```bash
# Using npm
npm install
npm run dev

# Or single-enter bash orchestration
./deploy.sh
```
